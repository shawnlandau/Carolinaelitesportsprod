# Images Folder

Add your images to this folder:

## Required Images

### Logo
- **carolina-rays-logo.png** - Main logo for the header
  - Recommended size: 300x100px (or maintain aspect ratio)
  - Format: PNG with transparent background

### Staff Photos
- **staff-[name].jpg** - Photos of coaching staff
  - Recommended size: 400x400px (square format)
  - Format: JPG or PNG
  - Example: `staff-john-smith.jpg`

### Alumni Photos
- **alumni-[name].jpg** - Photos of alumni players
  - Recommended size: 600x450px (4:3 aspect ratio)
  - Format: JPG or PNG
  - Example: `alumni-mike-jones.jpg`

### Sponsor Logos
- **sponsor-[company].png** - Sponsor/partner logos
  - Recommended size: 300x200px (or maintain aspect ratio)
  - Format: PNG with transparent background
  - Example: `sponsor-local-business.png`

### Additional Images (Optional)
- Facility photos
- Team photos
- Action shots from games/training
- Event photos

## Image Optimization Tips

1. **Compress Images:** Use tools like TinyPNG or ImageOptim before uploading
2. **Proper Sizing:** Don't upload huge images - resize to recommended dimensions
3. **File Naming:** Use descriptive, lowercase names with hyphens (e.g., `indoor-facility-main.jpg`)
4. **Format Choice:**
   - Use PNG for logos and graphics with transparency
   - Use JPG for photos
   - Use WebP for best compression (if browser support isn't a concern)
